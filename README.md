# Focus Grove

Focus Grove is a colorful, pixel-art study tracker for ICSE Class 10 students. It helps you plan your studies, stay focused, and make steady progress through a virtual flower grove.

## What you can do

- Track progress through your syllabus.
- Use a 30-minute focus timer for study sessions.
- Grow a virtual flower grove as you make progress.
- Practice with interactive quizzes.

## Getting started

This is an Android app built with Kotlin and Jetpack Compose. To explore or build it, open the project in Android Studio and let Gradle sync. You may need to configure the project’s environment or Firebase settings; use `.env.example` as a reference and never commit private keys or secrets.
